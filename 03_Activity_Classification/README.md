# Activity Classification and Validation

This stage focuses on developing and evaluating a two-dimensional rule-based classifier for nonprofit healthcare organizations that could not be matched to specific diseases using the DALY–MeSH dictionary.

The classifier assigns two complementary dimensions:

- **Main Theme:** The primary area of healthcare-related activity.
- **Organization Type:** The organization's functional role or operational model.

## Methodology

The classification process includes:

1. Development and refinement of classification rules using a revenue-based Pareto sample.
2. Automated classification of nonprofit organizations.
3. Selection of an independent random validation sample of 95 organizations.
4. Comparison of automated classifications with manually assigned labels.
5. Evaluation of classification agreement and identification of cases requiring further review.

## Project Files

The directory contains Python scripts for classification, sampling, and validation, along with relevant Excel input and output files.

Each script is documented with its purpose, required input files, processing steps, and generated outputs.
